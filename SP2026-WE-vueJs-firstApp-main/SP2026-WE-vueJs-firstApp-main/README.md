# Expense Splitter - Vue 3 App

## Project Overview
A simple Expense Splitter application built with Vue 3 and Vite. Users can register participants, split bills equally, and view history.

## Features
- Register participants with name, email, and password
- Add and remove participants
- Enter total bill and see equal split summary
- Automatic history tracking with dates
- Clean light blue theme
